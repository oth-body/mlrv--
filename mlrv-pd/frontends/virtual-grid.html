Virtual monome grid

A browser stand-in for the hardware. Presses dispatch the same x y state tuple mapping.pd expects; LEDs light up exactly as the device would respond.

Grid

Click any cell to send a press event. The mapping rule: y=7, slot=x. Press (7,0) for stopall.
trigger row: y=7 (lit in orange)
slot row: x=0..7 → file_poly slot 0..7
active voices: 0

Mapping cheat sheet

Press (x, 7)  → play slot x
Press (0, 7)  → stopall
Release anywhere  → ignored (current rule)
Press (x, y≠7)  → ignored (current rule)
